## Project Overview
I was investigating a common digital purchase scam where users would buy items from each other and some groups of users would take money without providing the items. This became a project for me after a friend got scammed from a user on the steam marketplace. Through this project, I discovered several operational security issues with the scam and got it taken down legally.
